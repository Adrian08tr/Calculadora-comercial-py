## Sobre o Projeto

A Calculadora Comercial é um projeto acadêmico desenvolvido em grupo
no primeiro semestre do curso de Engenharia de Software.

A aplicação foi criada em Python com a biblioteca Tkinter, permitindo
realizar cálculos relacionados ao fechamento de caixa diário.

## Objetivo

Simplificar cálculos comerciais básicos, auxiliando na apuração do saldo
final a partir das vendas, despesas e comissão.

## Funcionalidades

- Entrada do total de vendas.
- Entrada do total de despesas.
- Definição da taxa de comissão.
- Cálculo automático da comissão.
- Cálculo do saldo final.
- Tratamento de entradas numéricas inválidas.

## Tecnologias Utilizadas

- Python
- Tkinter
